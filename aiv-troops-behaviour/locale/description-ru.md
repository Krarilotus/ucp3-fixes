# ИИ: Поведение войск AIV

Восстанавливает отсутствующие позиции AIV для пикинёров, мечников и арабских мечников. Добавляет настройки использования позиций войсками ИИ.

- Выбрать, защищают ли стартовые войска замок или роют ров.
- Оставить защитников на позициях или отправить их патрулировать.
- Задать общие настройки для всех ИИ и отдельные настройки для типов войск, включая рабов.
- Используйте именованные значения AIC для каждого ИИ: InitialRole = "defend"/"dig", Movement = "hold"/"patrol". Пропущенные поля наследуют настройки по умолчанию. Точные имена приведены в разделе Поля AIC и приоритет в настройках.

Рытьё доступно только войскам, которые умеют копать. Настройки находятся в разделе **ИИ → Поведение войск AIV**. Дополнительные настройки по умолчанию выключены. После изменений перезапустите игру и начните новую партию.
