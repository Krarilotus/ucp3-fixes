# ИИ: Поведение войск AIV

Восстанавливает отсутствующие позиции AIV пикинёров и обоих типов мечников. Дополнительные настройки управляют начальной ролью и движением защитников для всех 15 типов войск.

Для каждого типа войск выберите защиту или рытьё, удержание позиции или патрулирование. Рытьё доступно только способным к нему войскам.

Для отдельных ИИ: `AIVTroops_InitialRole_<Troop>` (`"defend"` / `"dig"`) и `AIVTroops_Movement_<Troop>` (`"hold"` / `"patrol"`). Без суффикса войск настройка общая для ИИ; общая роль принимает только `"defend"`. Включённые переопределения AIC приоритетнее; пропущенные поля наследуют настройки.

Пример: `AIVTroops_InitialRole_Slave: "dig"` назначает рабов землекопами. Названия войск и подробности — в [справочнике AIC](https://github.com/UnofficialCrusaderPatch/UCP-Wiki/blob/docs/extension-aic-fields/docs/Stronghold-Crusader-Wiki/AI-Lords/AI-Character-Parameters.md#aiv-troop-behaviour).

Настройки войск изначально выключены. После изменений перезапустите игру и начните новую партию.
