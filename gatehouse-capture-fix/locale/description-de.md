# Korrektur der Torhauseroberung

Lebende Truppen entscheiden über die Kontrolle eines Torhauses. Gefallene Truppen erobern oder verteidigen es nicht mehr.

Standardmäßig deaktiviert: Die Auswahl dieses Moduls allein ändert das Spiel nicht. Schalte die Korrektur unter **Fehlerkorrekturen** ein oder wähle das Plugin **UCP3 Fixes**, das sie aktiviert.
