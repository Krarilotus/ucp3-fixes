# Corrección de captura de puertas

Las tropas vivas deciden quién controla una puerta. Las tropas caídas ya no la capturan ni defienden.

Desactivado por defecto: seleccionar solo este módulo no cambia el juego. Activa la corrección en **Correcciones**, o selecciona el plugin **UCP3 Fixes**, que la activa.
