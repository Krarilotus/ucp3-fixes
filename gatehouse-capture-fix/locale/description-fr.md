# Correction de la capture des portes

Les troupes vivantes décident du contrôle d'une porte. Les troupes tombées ne la capturent ni ne la défendent plus.

Désactivé par défaut : sélectionner ce module seul ne modifie pas le jeu. Activez le correctif sous **Corrections**, ou sélectionnez le plugin **UCP3 Fixes**, qui l'active.
