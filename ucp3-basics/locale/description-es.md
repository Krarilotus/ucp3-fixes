# UCP3 Basics

La configuración estándar de UCP3. Selecciona:

- **UCP2 Legacy Defaults**: UCP2 Legacy con sus ajustes predeterminados, junto con los archivos de IA, el parche AIC y los castillos de IA originales corregidos (AIV) que incluye;
- **Graphics API Replacer**.

Nada más: sin correcciones adicionales, sin texturas nuevas ni reequilibrio del juego. En la familia UCP3 puedes cambiar a **Básica + Correcciones** o **Recomendada** para obtener más.

Requiere el lanzador 1.0.17 o posterior.
