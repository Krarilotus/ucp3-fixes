# UCP3 Recommended

UCP3 Basics + Fixes, plus :

- **ConqueringArabia** : la version retravaillée par Monsterfish des textures d'origine de Crusader, avec diverses corrections de textures (sans neige) ;
- les fonctions d'interface de **Interface and Visual Fixes** : la description de la carte sélectionnée reste visible dans le salon, et le bouton Charger s'affiche dans le salon d'escarmouche ;
- **Build Over Workers** : placez des bâtiments et des murs sur des cases occupées par vos propres ouvriers ou ceux de vos alliés ; ils s'écartent vers une case libre au lieu d'être supprimés.

En dehors de la règle de placement de Build Over Workers, il n'y a aucun rééquilibrage du jeu, aucune modification de l'IA et aucune texture de neige. Les correctifs, les fonctions d'interface et le placement sur les ouvriers peuvent être désactivés dans Personnalisations. ConqueringArabia n'a pas d'option dédiée : choisissez **Base** ou **Base + Correctifs** pour conserver les textures d'origine. **Base** sélectionne les mêmes paquets que la configuration par défaut précédente.

Nécessite le lanceur 1.0.17 ou une version ultérieure.
