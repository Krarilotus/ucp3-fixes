# Поиск пути

Общий компонент для модулей, которые меняют то, как юниты находят дорогу. Сам по себе он ничего в игре не меняет.

И Smarter Pathing (сокращение пути ассасинов), и Gatehouse Fixes (правила маршрутов через ворота) используют игровой поиск пути для юнита. Этот модуль позволяет им работать вместе: каждый добавляет сюда своё правило, и каждое правило видит нужного юнита. Другие модули устанавливают его автоматически, когда он им нужен.
