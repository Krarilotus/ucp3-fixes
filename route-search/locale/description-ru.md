# Поиск пути

Общий компонент для модулей, которые меняют то, как юниты находят дорогу. Сам по себе он ничего в игре не меняет.

И Smarter Pathing (сокращение пути ассасинов), и Gatehouse Fixes (правила маршрутов через ворота) меняют поиск пути, который игра запускает, когда юнит получает новую цель движения. «Поиск пути» позволяет им работать вместе — каждый добавляет сюда своё правило, и каждое правило видит нужного юнита. Его используют только те версии этих модулей, которые от него зависят, и они же устанавливают его автоматически.
