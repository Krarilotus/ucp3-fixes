# Поиск пути

Общий компонент для модулей, которые меняют то, как юниты находят дорогу. Сам по себе он ничего в игре не меняет.

Smarter Pathing (короткий путь для ассасинов) и Gatehouse Fixes (правила прохода через ворота) меняют то, как игра ищет путь, когда юниту указывают новый пункт назначения. Модуль «Поиск пути» позволяет им работать вместе. Каждый модуль добавляет своё правило, и каждое правило учитывает юнита, для которого игра ищет путь. Только те версии этих модулей, у которых «Поиск пути» указан в зависимостях, используют его и устанавливают автоматически.
