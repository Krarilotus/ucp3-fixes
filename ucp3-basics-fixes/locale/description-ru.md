# UCP3 Basics + Fixes

UCP3 Basics plus **UCP3 Fixes**: the previous default setup with the reviewed bug fixes switched on (worker deliveries, gatehouse capture, hunters, siege crews, AI hop-farm counting, AI castle troop positions, and interface, visual and audio fixes).

The game still looks and plays as before: no new textures, no snow textures, no gameplay rebalancing. Each fix can be switched off in Customizations. Choose **Basics** for the previous default without the fixes, or **Recommended** for more.
