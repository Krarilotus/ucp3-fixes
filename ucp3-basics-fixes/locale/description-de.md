# UCP3 Basics + Fixes

UCP3 Basics plus **UCP3 Fixes**: die Standard-Konfiguration mit eingeschalteten geprüften Fehlerkorrekturen (Warenlieferungen, Torhauseroberung, Jäger, Belagerungsbesatzungen, KI-Hopfenfarmzählung, Truppenpositionen in KI-Burgen sowie Oberflächen-, Grafik- und Audiokorrekturen).

Das Spiel sieht weiterhin genauso aus und spielt sich wie zuvor: keine neuen Texturen, keine Schneetexturen, keine Balance-Änderungen. Jede Korrektur lässt sich unter Anpassungen ausschalten. Wähle **Basis** für die Standard-Konfiguration ohne Korrekturen oder **Empfohlen** für mehr.

Erfordert Launcher 1.0.17 oder neuer.
