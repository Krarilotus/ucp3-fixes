# IA : Correction du comptage des houblonnières

Compte les houblonnières dans la limite de fermes de l’IA, comme les fermes de blé, les pommeraies et les laiteries. La limite reste inchangée.

Désactivé par défaut : sélectionner ce module seul ne modifie pas le jeu. Activez le correctif sous **IA → Correctifs**, ou sélectionnez le plugin **UCP3 Fixes**, qui l’active. Redémarrez le jeu après modification.
