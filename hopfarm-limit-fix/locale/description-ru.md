# ИИ: Исправление подсчёта хмелевых ферм

Учитывает хмелевые фермы в лимите ферм ИИ наряду с пшеничными фермами, яблоневыми садами и молочными фермами. Сам лимит не меняется.

По умолчанию отключено: выбор одного лишь этого модуля не меняет игру. Включите исправление в разделе **ИИ → Исправления** или выберите плагин **UCP3 Fixes**, который включает его. После изменений перезапустите игру.
