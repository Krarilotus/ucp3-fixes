# KI: Korrekte Zählung von Hopfenfarmen

Zählt Hopfenfarmen beim Farmlimit der KI mit, genau wie Weizen-, Apfel- und Milchfarmen. Das Limit selbst bleibt gleich.

Standardmäßig deaktiviert: Die Auswahl dieses Moduls allein ändert das Spiel nicht. Schalte die Korrektur unter **KI → Fehlerbehebungen** ein oder wähle das Plugin **UCP3 Fixes**, das sie aktiviert. Nach Änderungen das Spiel neu starten.
