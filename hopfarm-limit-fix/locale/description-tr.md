# Yapay zekâ: Şerbetçiotu çiftliği sayım düzeltmesi

Şerbetçiotu çiftliklerini, buğday ve süt çiftlikleri ile elma bahçeleri gibi yapay zekânın çiftlik sınırına dâhil eder. Sınırın kendisi değişmez.

Varsayılan olarak kapalıdır: Yalnızca bu modülü seçmek oyunu değiştirmez. Düzeltmeyi **Yapay zekâ → Düzeltmeler** altında açın veya bunu açan **UCP3 Fixes** eklentisini seçin. Değişikliklerden sonra oyunu yeniden başlatın.
