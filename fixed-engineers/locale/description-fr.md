# Corrections des ingénieurs

Corrige la gestion des équipages de siège, protège les ingénieurs quand ils quittent un engin et arrête les catapultes et trébuchets mobiles quand ils visent une unité. Redémarrez le jeu après modification.

Les deux correctifs sont désactivés par défaut : sélectionner ce module seul ne modifie pas le jeu. Activez-les sous **Corrections**, ou sélectionnez le plugin **UCP3 Fixes**, qui les active.
