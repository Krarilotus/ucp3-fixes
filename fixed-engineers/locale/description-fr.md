# Corrections des ingénieurs

Corrige la suppression ignorée des équipages de siège et rejette les références périmées lors de la sortie d'un engin. Les ingénieurs survivants conservent leur identité et leur santé. Redémarrez le jeu après une modification.

Activé par défaut une fois sélectionné ; désactivable dans Personnalisations → Corrections. Cette version de test corrige le traitement omis des équipages morts et les références périmées lors du démontage. Les quotas de recrutement restent inchangés. AI Swapper gère les troupes initiales ; Improved Tunnelers gère les tunneliers. Ne pas activer simultanément l’ancien module Unit Behaviour Fixes.
