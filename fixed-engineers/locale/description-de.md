# Ingenieurkorrekturen

Korrigiert die Besatzung von Belagerungsgeräten, schützt Ingenieure beim Aussteigen und hält fahrende Katapulte und Triboke beim Zielen an. Nach Änderungen das Spiel neu starten.

Beide Korrekturen sind standardmäßig deaktiviert: Die Auswahl dieses Moduls allein ändert das Spiel nicht. Schalte sie unter **Fehlerkorrekturen** ein oder wähle das Plugin **UCP3 Fixes**, das sie aktiviert.
