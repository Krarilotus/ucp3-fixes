# Исправления инженеров

Исправляет пропуск удаления осадных экипажей и отклоняет устаревшие ссылки при выходе из машины. Выжившие инженеры сохраняют свою личность и здоровье. После изменения перезапустите игру.

Включено по умолчанию при выборе; отключается в настройках → Исправления ошибок. Тестовая версия исправляет пропущенную обработку гибели экипажа и устаревшие ссылки при выходе из орудия. Лимиты найма не меняются. Начальные войска настраиваются в AI Swapper, поведение туннельщиков — в Improved Tunnelers. Не включайте старый модуль Unit Behaviour Fixes одновременно с этим.
