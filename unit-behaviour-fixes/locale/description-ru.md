# Исправления поведения юнитов

Исправляет пропуск удаления экипажей осадных машин. Бездействующие туннельщики используют обычную реакцию на ближайших врагов в соответствии с режимом своей группы.

Оба исправления включены по умолчанию при выборе модуля и отключаются отдельно в настройках: экипажи в разделе исправлений, реакция туннельщиков в ИИ / Исправления. После изменения перезапустите игру.

Тестовая версия для одиночной игры. Полный жизненный цикл экипажей, подсчёт при найме и проверка в игре ещё не завершены. Начальные войска настраиваются в AI Swapper. Сетевые тесты выполняют игроки.
