# Удаление осадного экипажа

Исправляет пропуск удаления экипажа в начале анимации уничтожения осадной машины. После изменения настройки перезапустите игру.

Тестовая разработка, не готовый выпуск. Урон от огня, остальные проверки жизненного цикла экипажа и учёт найма ещё не завершены. Только одиночное тестирование. При выборе модуля настройка включена по умолчанию.
