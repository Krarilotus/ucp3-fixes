# Unit Behaviour Fixes

Correct skipped siege crew cleanup and let idle tunnelers use the ordinary nearby-enemy response governed by their group stance.

Both fixes default to on when this module is selected. Disable them independently in Customizations: Siege crew cleanup under Bugfixes; Tunneler combat response under AI / Fixes. Restart the game after changing a switch.

Single-player test candidate. Complete crew lifecycle, recruitment accounting and gameplay acceptance remain unfinished. This package does not add starting troops; those are configured in AI Swapper. Multiplayer testing belongs to players.
