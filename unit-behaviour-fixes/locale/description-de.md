# Belagerungsbesatzung entfernen

Behebt das übersprungene Entfernen der Besatzung zu Beginn der Zerstörungsanimation einer Belagerungsmaschine. Nach einer Änderung das Spiel neu starten.

Entwicklungsversion, keine Veröffentlichung. Feuerschaden, weitere Prüfungen des Besatzungslebenszyklus und die Rekrutierungszählung sind noch nicht fertig. Nur Einzelspielertests. Die Option ist bei Auswahl dieses Moduls standardmäßig aktiviert.
