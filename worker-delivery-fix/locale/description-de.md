# Korrektur der Warenlieferung

Arbeiter können erreichbare Kornspeicher und Waffenkammern beliefern, auch wenn der Weg vom Bergfried blockiert ist. Die KI behält diese Lager trotz der Blockade.

Standardmäßig deaktiviert: Die Auswahl dieses Moduls allein ändert das Spiel nicht. Schalte die Korrektur unter **Fehlerkorrekturen** ein oder wähle das Plugin **UCP3 Fixes**, das sie aktiviert.
