# İşçi teslimatı düzeltmesi

İşçiler, iç kaleden gelen yol kapalı olsa bile ulaşabildikleri ambara veya cephaneliğe mal teslim edebilir. Yapay zekâ bu binaları yol kapalıyken korur.

Varsayılan olarak kapalıdır: Yalnızca bu modülü seçmek oyunu değiştirmez. Düzeltmeyi **Hata düzeltmeleri** altında açın veya bunu açan **UCP3 Fixes** eklentisini seçin.
