# Correction des livraisons

Les ouvriers peuvent livrer aux greniers et armureries accessibles même si le chemin depuis le donjon est bloqué. L'IA conserve ces bâtiments pendant le blocage.

Désactivé par défaut : sélectionner ce module seul ne modifie pas le jeu. Activez le correctif sous **Corrections**, ou sélectionnez le plugin **UCP3 Fixes**, qui l'active.
