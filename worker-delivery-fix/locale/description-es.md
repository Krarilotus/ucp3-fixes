# Corrección de la entrega de mercancías

Los trabajadores pueden entregar mercancías a graneros y arsenales accesibles aunque esté bloqueada la ruta desde la fortaleza. La IA conserva esos edificios durante el bloqueo.

Desactivado por defecto: seleccionar solo este módulo no cambia el juego. Activa la corrección en **Correcciones**, o selecciona el plugin **UCP3 Fixes**, que la activa.
