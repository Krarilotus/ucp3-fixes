# Build Over Workers

Позволяет возводить здания и стены там, где стоят дружественные рабочие. Рабочие отходят на ближайшую свободную клетку, если она есть. Размещение зданий и стен настраивается раздельно.

По умолчанию отключено: выбор одного лишь этого модуля не меняет игру. Включите нужные пункты в разделах **Исправления** и **Изменения баланса** или выберите конфигурацию **UCP3 Recommended**, которая включает их все.
