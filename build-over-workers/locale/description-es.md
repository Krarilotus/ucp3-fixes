# Build Over Workers

Permite colocar edificios o muros donde haya trabajadores amigos. Los trabajadores se apartan a una casilla libre cercana si hay alguna disponible. La colocación de edificios y muros se puede configurar por separado.

Desactivado por defecto: seleccionar solo este módulo no cambia el juego. Activa las partes que quieras en **Correcciones** y **Cambios de equilibrio**, o selecciona la configuración **UCP3 Recommended**, que las activa todas.
