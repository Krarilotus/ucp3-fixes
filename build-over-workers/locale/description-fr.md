# Build Over Workers

Permet de placer des bâtiments ou des murs là où se trouvent des ouvriers amis. Les ouvriers s'écartent vers une case libre voisine lorsqu'il y en a une. Le placement des bâtiments et des murs se configure séparément.

Désactivé par défaut : sélectionner ce module seul ne modifie pas le jeu. Activez les options souhaitées sous **Corrections** et **Modifications de l'équilibrage**, ou sélectionnez la configuration **UCP3 Recommended**, qui les active toutes.
