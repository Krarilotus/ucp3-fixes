# Build Over Workers

Ermöglicht das Platzieren von Gebäuden und Mauern dort, wo freundliche Arbeiter stehen. Die Arbeiter weichen auf ein nahes freies Feld aus, sofern eines verfügbar ist. Gebäude- und Mauerplatzierung lassen sich getrennt einstellen.

Standardmäßig deaktiviert: Die Auswahl dieses Moduls allein ändert das Spiel nicht. Schalte die gewünschten Teile unter **Fehlerkorrekturen** und **Balance-Änderungen** ein oder wähle die Konfiguration **UCP3 Recommended**, die alle aktiviert.
